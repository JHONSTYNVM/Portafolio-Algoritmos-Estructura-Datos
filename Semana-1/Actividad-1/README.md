# ACTIVIDAD 1

## Implementación de Operaciones con Arreglos en Java

En esta actividad se desarrolló una aplicación en Java utilizando Apache NetBeans para trabajar con arreglos de números enteros.

Se implementaron métodos para:

- Eliminar un elemento.
- Modificar un elemento.
- Insertar un elemento en una posición determinada.
- Sumar los elementos del arreglo.
- Hallar el número menor, mayor y promedio.
- Sumar los elementos impares.
- Mover el primer elemento al final.
- Mover el primer elemento par al final.

## Contenido

- Proyecto desarrollado en Apache NetBeans.
- Informe completo de la Actividad 1.
