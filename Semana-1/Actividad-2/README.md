# ACTIVIDAD 2

## Registro, Validación y Cálculo de Promedio de Prácticas en Java

En esta actividad se desarrolló una aplicación en Java utilizando Apache NetBeans para registrar y procesar las notas de las prácticas de un alumno.

Se implementaron métodos para:

- Crear el registro de prácticas.
- Ingresar y validar las notas.
- Mostrar las notas almacenadas.
- Identificar la nota más baja.
- Calcular el promedio eliminando la nota menor.
- Mostrar el promedio redondeado.
- Validar que las notas se encuentren entre 0 y 20.

## Contenido

- Proyecto desarrollado en Apache NetBeans.
- Informe completo de la Actividad 2.
