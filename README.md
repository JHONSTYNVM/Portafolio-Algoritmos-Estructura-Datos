## DESCRIPCIÓN

Este repositorio contiene las actividades, ejercicios y proyectos desarrollados durante el curso de **Algoritmos y Estructura de Datos**.

Los trabajos están organizados por semanas. Cada actividad incluye el proyecto desarrollado en **Java mediante Apache NetBeans** y su respectivo **informe académico**, donde se presentan el enunciado, TDA, explicación del código, capturas de ejecución, resultados y conclusiones.

# SEMANA 01

## Actividad 1: Implementación de Operaciones con Arreglos en Java

Desarrollo de diferentes operaciones sobre arreglos utilizando métodos, estructuras condicionales y estructuras repetitivas en Java.

**Contenido:**

- Proyecto desarrollado en Apache NetBeans
- Informe completo de la actividad

## Actividad 2: Registro, Validación y Cálculo de Promedio de Prácticas en Java

Aplicación para registrar y validar las notas de las prácticas de un alumno, identificar la nota más baja, excluirla del cálculo y obtener el promedio redondeado.

**Contenido:**

- Proyecto desarrollado en Apache NetBeans
- Informe completo de la actividad
